📚 Lista Completa de Comandos iGunsFire

GM / MOD /ban [ID] [Días] [Razón]
Baneo de cuenta por días. "e" para eterno (Solo ID 2).
GM / MOD /gm_mute [ID] [Horas]
Silencia al usuario en el chat. Máximo 5 horas.
GM / MOD /unmuted [ID] [Horas]
Quita el silencio de chat al GM que lo usa.
GM / MOD /info [Nombre]
Ver ID, Cash, Gold, IP y Stats de un jugador.
GM / MOD /find_ip [ID]
Busca a otros usuarios conectados con la misma IP que el ID dado.
GM / MOD /regalo [ID] [AvatarID]
Envía un avatar específico de regalo a un usuario.
GM / MOD /borrar_avatar [ID] [AvaID]
Elimina una sola prenda específica del inventario de un usuario.
GM / MOD /trivia [Monto] "P" [R]
Inicia trivia por Cash con ventana pop-up dorada.
GM / MOD /regalo_suerte [Monto]
Suelta un premio de Cash. El primero en escribir /yo gana.
GM / MOD /super_set [Monto]
Regalar super set alos nuevos usuarios/yo gana.
GM / MOD /aviso [Mensaje]
Envía una ventana emergente (Alerta 17) a todo el servidor.
GM / MOD /mall [Mensaje] [Mensaje]
Mensaje de corneta (Bugle) para todos los servidores.
GM / MOD /mserver [Mensaje]
Mensaje de corneta (Bugle) solo para el servidor actual.
GM / MOD /lobby_msj [Texto]
Fija un mensaje rosa (LOVE) en el chat del lobby.
GM / MOD /lobby_msj_clear
Elimina el mensaje fijado del lobby.
GM / MOD /bomba [Tamaño]
Carga una bala que destruye el mapa. Tamaño máximo 180.
GM / MOD /rayo [Tamaño]
Fuerza que caiga un rayo en el punto de impacto del disparo.
GM / MOD /mastergm [Tamaño]
Quita el master al dueño actual y te lo da a ti.
GM / MOD /pull [ID] [Tamaño]
Jala a un usuario de cualquier parte a tu sala actual.
GM / MOD /champions_start
Dar inicio ala champios.
GM / MOD /reset_champions
Reinicia el servidor de League/Champions por completo.
GM / MOD /sudden
Activar muerte subita
GM / MOD /start
Dar ready ala partida cuando esten completos los jugadores
GM / MOD /kick_all
Botar a todos los que estan en la sala
GM / MOD /room100
la sala se convierte en 100vs100
GM / MOD /evento HORAS PORCENTAJE
ejemlo /evento 1 300 (se activa 1 hora de vento 300%).
GM / MOD /vs [RoomID] | /vs2 [Nombre]
Entrar a observar una partida como espectador.
VENTAS GM /recarga [ID] [Monto]
Venta de cash tradicional. Otorga VIP y regalos de escala.
VENTAS GM /oferta [ID] [Monto]
Similar a recarga pero usando la tabla de ofertas (13, 18, 29...).
VENTAS GM /pin_manual [Monto]
Crea un código PIN corto para copiar y pegar en el chat.
VENTAS GM /pin_code [Tipo]
Genera PIN de formato largo para reclamar en la web.
VENTAS GM /mi_saldo
ver mi saldo disponible.
